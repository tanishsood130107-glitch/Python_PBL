# Customer Behavior Segmentation

## 📌 Project Overview

**Customer Behavior Segmentation** is a machine learning project that analyzes retail customer purchasing behavior and groups customers into meaningful segments based on their spending patterns, purchase frequency, quantity, returns, and recency.

The project uses **Python, data preprocessing, exploratory data analysis, feature scaling, and unsupervised machine learning techniques** to identify different customer behavior patterns.

The main objective is to help businesses understand their customers better and support **targeted marketing, customer retention, and personalized strategies**.

---

## 🎯 Problem Statement

Businesses often have customers with very different purchasing behaviors. Treating all customers in the same way can lead to ineffective marketing and poor resource allocation.

This project addresses the problem by analyzing customer transaction behavior and dividing customers into distinct behavioral groups.

The segmentation is based on factors such as:

- Total spending
- Purchase frequency
- Total quantity purchased
- Number of returned items
- Return ratio
- Spending per item
- Recency
- Product category

---

## 🎯 Objectives

The major objectives of this project are:

- Analyze customer purchasing behavior.
- Clean and preprocess the retail dataset.
- Identify important behavioral features.
- Explore relationships between customer attributes.
- Apply clustering techniques for customer segmentation.
- Compare clustering results using evaluation metrics.
- Identify meaningful customer groups.
- Provide a foundation for targeted marketing strategies.

---

## 📊 Dataset

The project uses a retail customer dataset containing behavioral information for individual customers.

### Important Features

| Feature | Description |
|---|---|
| `CUSTOMER_ID` | Unique identifier of the customer |
| `TOTAL_SPENDING` | Total amount spent by the customer |
| `FREQUENCY` | Frequency of customer purchases |
| `TOTAL_QUANTITY` | Total quantity of products purchased |
| `NO_OF_ITEMS_RETURNED` | Number of returned items |
| `RETURN_RATIO` | Ratio of returned items to purchased items |
| `PRODUCT_CATEGORY` | Category of products purchased |
| `SPENDING_PER_ITEM` | Average spending per purchased item |
| `RECENCY` | Time since the customer's most recent purchase |

### Product Categories

The dataset includes categories such as:

- Kitchenware
- Toys
- Home Decor
- Groceries
- Clothing
- Others
