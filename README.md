# Customer Behavior Segmentation

## Project Overview

**Customer Behavior Segmentation** is a machine learning project that analyzes retail customer purchasing behavior and groups customers into meaningful segments based on their spending patterns, purchase frequency, quantity, returns, and recency.

The project uses **Python, data preprocessing, exploratory data analysis, feature scaling, and unsupervised machine learning techniques** to identify different customer behavior patterns.

The main objective is to help businesses understand their customers better and support **targeted marketing, customer retention, and personalized strategies**.

---

## Problem Statement

Businesses often have customers with very different purchasing behaviors. Treating all customers in the same way can lead to ineffective marketing and poor resource allocation.

This project addresses the problem by analyzing customer transaction behavior and dividing customers into distinct behavioral groups.

The segmentation is based on factors such as:

- Total spending
- Purchase frequency
- Total quantity purchased
- Number of returned items
- Return ratio
- Spending per item
- Recency
- Product category

## Project Workflow

**Retail Customer Data → Data Cleaning & Preprocessing → Exploratory Data Analysis → Feature Selection → Feature Scaling → Clustering → Model Evaluation → Customer Segmentation → Behavioral Insights**

### Phase 1 — Data Preparation & Exploration

The first phase focuses on understanding and preparing the dataset.

- Activities performed
- Loaded the retail dataset using Python.
- Inspected the dataset structure.
- Checked data types and missing values.
- Examined customer behavior variables.
- Performed data cleaning.
- Conducted exploratory data analysis.
- Visualized important relationships and distributions.

The cleaned data was then prepared for machine learning.

### Phase 2 — Feature Engineering & Clustering

The second phase focuses on transforming the customer data into a form suitable for clustering.

Feature Scaling

Since the behavioral variables have different ranges, StandardScaler was used to standardize the numerical features.

Standardization prevents variables with larger numerical ranges from dominating the clustering algorithm.

The scaled features were then used for unsupervised learning.

---

### Phase 3 — Customer Segmentation & Final Analysis

The third phase focuses on analyzing the clustering results and converting the generated clusters into meaningful customer segments.

### Activities Performed

- Analyzed the clusters generated by the clustering algorithms.
- Compared customer behavior across different clusters.
- Examined spending, purchase frequency, quantity, returns, and recency for each cluster.
- Interpreted the characteristics of each customer group.
- Assigned descriptive labels to the identified customer segments.
- Visualized the final customer segments for better interpretation.
- Compared clustering performance using the Silhouette Score.

### Customer Segments

Based on the behavioral characteristics of the clusters, customers can be categorized into descriptive groups such as:

| Segment | General Characteristics |
|---|---|
| **Low** | Lower spending and purchase activity |
| **Medium** | Moderate purchasing activity |
| **High** | Higher spending and purchase frequency |
| **VIP** | High-value and highly active customers |
| **Royal** | Customers showing the strongest overall purchasing behavior |

> **Note:** These labels are descriptive and are assigned based on the characteristics of each generated cluster. The clustering algorithm itself does not assign labels such as VIP or Royal.

### Outcome

The final analysis converts the clustering results into **meaningful customer segments** that can support targeted marketing, customer retention, personalized offers, and business decision-making.

---

### K-Means Clustering

K-Means clustering was used to group customers with similar purchasing behavior.

The algorithm divides customers into K clusters by minimizing the distance between customers and their corresponding cluster centroids.

Different values of K were tested and evaluated using the Silhouette Score.

### DBSCAN Clustering

The project also explored DBSCAN (Density-Based Spatial Clustering of Applications with Noise).

The configuration used:

eps = 0.5
minPts = 10

The resulting silhouette score was:

0.718789

DBSCAN was explored as an alternative to centroid-based clustering because it can identify dense groups and handle noise/outliers.

### Model Evaluation

The Silhouette Score was used to evaluate the quality of the generated clusters.

A higher silhouette score generally indicates that observations are relatively well separated from other clusters while remaining close to observations within their own cluster.

The clustering approaches were therefore compared using their calculated scores rather than relying only on visual inspection.

### Customer Segmentation

The purpose of the clustering stage is to transform raw customer behavior into meaningful behavioral segments.

The project uses descriptive segment labels such as:

Low
Medium
High
VIP
Royal

These labels represent customer value/behavior categories and can be assigned after analyzing the characteristics of each generated cluster.

#### Note: Cluster numbers generated by machine learning algorithms do not inherently represent customer value. The final labels should therefore be interpreted from the behavioral characteristics of each cluster.
